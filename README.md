# Pizza Billing System (Java)

A console-based Java application calculates pizza bills based on type (Veg/ Non-veg),extra cheese, extra toppings and takeaway option.

## Features
- Veg & Non-veg pizza pricing
- Extra cheese and toppings
- Takeaway charges
- Object-Oriented design(Inheritance)

## Technologies Used
- Java
- Eclipse IDE
- Git & GitHub
